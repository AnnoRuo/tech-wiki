## 概述

在 Java 中，所有类都直接或间接地继承自 `Object`。当你没有使用 `extends` 显式指定父类时，编译器会自动让你的类隐式继承 `Object`。显式继承则通过 `extends` 关键字实现：

```
class Sub extends Super {}
```

## 隐藏 & 封装



| 任何人      | 同一个包 | 子类 | 本类 |      |
| ----------- | -------- | ---- | ---- | ---- |
| `public`    | ✔️        | ✔️    | ✔️    | ✔️    |
| `protected` |          | ✔️    | ✔️    | ✔️    |
| `default`   |          |      | ✔️    | ✔️    |
| `private`   |          |      |      | ✔️    |

- 在继承时不允许降低父类方法的可访问性
- private 是隐式 final 的
- 如果无参构造器是唯一定义的构造器，并且它是 private 的，那么这就阻止了该类的继承！

再次强调：`private` 是编译期的语法约束，而非二进制层面的保护。它无法防止反编译。它的真正价值在于信息隐藏——将类的内部实现与公开接口明确分开。对类作者而言，这意味着可以自由修改内部实现而不必担心破坏外部依赖；对类使用者而言，这是一种减负：只需关注公开的接口，无需理解内部细节，从而更容易正确使用这个类。

## Object 与 Objects

- `static <T> void requireNonNull(T obj)`、`static <T> void requireNonNull(T obj, String message)`、`static <T> void requireNonNull(T obj, Supplier<String> messageSupplier)`：

  如果 obj 为 null ，这些方法将抛出指定消息（如果有的话）的 NullPointerException

- `static <T> T requireNonNullElse(T obj, T defaultObj)`、`static <T> T requireNonNullElseGet(T obj, Supplier<T> defaultSupplier)`：

  如果 obj 不是 null ，则返回 obj；如果 obj 为 null ，则返回默认对象
